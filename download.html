From download to desktop.

  1. Download the installerUse the green button to get McCreeperBrowser-Setup.exe from the GitHub release.
  2. Run the setupClose any older McCreeper window, open the installer, and choose your install folder and shortcuts.
  3. Start browsingOpen McCreeper Browser from your desktop or Start menu. Internet is required to load websites.
About Windows security warnings: This installer is unsigned, so Windows may show “Unknown publisher” or a SmartScreen warning. Confirm the file comes from this release before deciding whether to run it. Keep Windows protection enabled.

A few useful answers.

Is this Google Chrome?

No. McCreeper Browser is an independent Electron/Chromium app with a familiar browser layout. It does not include Chrome sync, saved Chrome passwords, or full Chrome Web Store support.

Will my Google account sign into everything?

Your Creeper Club login and Google website logins are separate. The profile button uses mccreeper.lol’s existing member login. Google may block sign-in in embedded views; use Gemini’s “Open in browser” option when needed.

How do I uninstall it?

Open Windows Settings → Apps → Installed apps, find McCreeper Browser, and choose Uninstall. The uninstaller preserves the browser’s user-data folder and bookmarks.

Does it update automatically?

The browser has no automatic app updater. Download and install a newer release when available. Website content updates as the websites change.

How can I check the downloaded file?

The SHA-256 for the version 2.1.0 installer is:
14a4f1618d96d691a79f939eaa81152604da6a5cb01d8e262b95809e334f4867

In PowerShell, run Get-FileHash "$env:USERPROFILE\Downloads\McCreeperBrowser-Setup.exe" -Algorithm SHA256 and compare the result. Adjust the file path if you saved it somewhere else. A matching hash confirms the file matches this release; it is not a safety certification.
